# Mohamed Saffiddine — project portfolio

The deployable website is `index.html`, `styles.css`, `site.js`, and `assets/` at the repository root. It is a static site: no dependencies or build command are needed.

Run locally from this directory:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

For Cloudflare Pages, publish the repository root as the static output directory. The original `Mohamed_Saffiddine_Cloudflare_Pages_v2.zip` is retained as the previous version; it is not the updated deployment package.

The Excel workbook and both supporting images are unchanged from the original archive. Displayed results use the workbook's saved values, not a new calculation. All company data is fictional or simulated.

The page includes a cash bridge and expandable assumptions, comparison tables, variance analysis, monthly cash balances, scenario analysis, and Excel formulas. The workbook is downloadable at `assets/Northstar_FPA_Operating_Model.xlsx`.
